Quase lá! O jogo precisa ser iniciado.

Você abriu o index.html diretamente. Como este projeto usa React e Vite, ele precisa ser servido localmente — não funciona abrindo este arquivo com dois cliques.

Como iniciar no Linux:

  1. Extraia a pasta do jogo.
  2. Abra essa pasta no VS Code e escolha Terminal → Novo Terminal.
  3. Execute os comandos abaixo, um de cada vez:
npm install npm run dev -- --open

O navegador abrirá o jogo automaticamente. Deixe o terminal aberto enquanto joga.

Se aparecer um erro no terminal, envie uma captura para que possamos corrigir a causa.
